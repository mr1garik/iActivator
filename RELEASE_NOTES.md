## iActivator 3.0.5

**Download:** Windows — `iActivator-windows-setup.exe` (installer, recommended) or `iActivator-windows-portable.zip` (no installation). macOS — `iActivator-macos.zip`.

### ⚠️ Windows: if you are still on 3.0.3 or older, install this by hand once
The stuck-on-"Installing…" update was fixed in 3.0.4. If you are already on 3.0.4, the in-app update to 3.0.5 installs itself. If you are on 3.0.3 or older, the update that brings you up still uses the old updater and can stall, so **close the app, download `iActivator-windows-setup.exe` and run it once.** Your history and settings are kept. On macOS the in-app update works as usual.

### What's new
- **No more duplicate copies in the tray.** Launching iActivator again while it was minimized to the tray (a shortcut, autostart, or a double click) used to start another copy and add another tray icon. Now the running window simply comes back to the front.
- **More reliable activation on Windows.** When the first activation attempt fails for a transient reason (the Apple USB service or the device not ready yet, a blip mid-handshake), the app now reconnects and retries automatically instead of failing, so iPhones activate on the first go more often. Activation Lock and other clear problems are reported at once, not retried.
- **Errors are surfaced automatically.** On any error a small notice appears with a one-tap button to open the report (device numbers hidden), so a problem can be sent without hunting for the button.
- **A fresh, hand-crafted look.** New warm colour identity in light and dark, a monospaced font for serial numbers, IMEIs and capacities, and a cleaner device panel.

iActivator activates and sets up iPhones through Apple's servers. It does not bypass iCloud Activation Lock.
