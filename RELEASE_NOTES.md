## iActivator 3.0.3

**Download:** Windows — `iActivator-windows-setup.exe` (installer, recommended) or `iActivator-windows-portable.zip` (no installation). macOS — `iActivator-macos.zip`.

**Have 3.0.1 or 3.0.2?** Press "Download & install" in the app — the update installs itself. **Have 3.0?** Download and install this version by hand once; after that updates install themselves. Your history and settings are always kept.

### What's new
- **History tools:** save a TXT file per phone, print QR-code stickers (with a template you can set and edit before printing), and keep service documents — intake/handover acts and a warranty certificate (your shop details go in Settings).
- **Statistics page:** activations and checks by period, with a 30-day activity chart.
- **Battery health over time:** the trend is shown per phone, so a replaced or worn battery stands out.
- **Setup presets:** save a named configuration (language, region, Wi-Fi, mode) and apply it with one click.
- **Owner Apple ID sign-in** to clear Activation Lock (the owner's own Apple ID — this is not a bypass), with a hint about the on-device "Unlock with Passcode" option.
- **More languages:** the interface is now available in Polish, Spanish and German as well as Russian, Ukrainian and English. The iPhone language and region lists are shown in a neutral form.
- **Keyboard shortcuts**, history filters by period and result, automatic cleanup of old history and files, a sound/notification when a phone is done, and new colour themes.
- Clearer Find My / MDM messages on new iOS, up-to-date iPhone and iPad names, and links now open reliably.

iActivator activates and sets up iPhones through Apple's servers. It does not bypass iCloud Activation Lock.
